🐉 โหมด RAYQUAZA

หน้าตาธีมมังกร มีลูกเล่นและเอฟเฟกต์ แถบขวาชื่อ RZ Plan ทุกฟีเจอร์เหมือนโหมดธรรมดา

📋 โหมดธรรมดา ORDOR

หน้าตาเรียบแบบเว็บ ORDOR เดิม แถบขวาชื่อ Plan Order ทุกฟีเจอร์ในคู่มือนี้ใช้ได้เหมือนกัน

สลับโหมดที่สวิตช์ [ RAYQUAZA | ธรรมดา ] บนแถบบนของโปรแกรม งานที่ทำค้างไว้ย้ายตามไปด้วย (ไฟล์ ORDER ตัวกรอง แบรนด์ที่เลือก ผลตรวจ และรายการในหน้า ก่อนสั่ง) ใช้เบราว์เซอร์ในตัว การล็อกอิน BigSeller และรอบตั้งเวลาชุดเดียวกัน

งานประจำวัน (เมนูซ้าย)

เมนูซ้ายมี 6 หน้า: นำเข้าข้อมูล · รับORDER · ก่อนสั่ง · ตรวจ ORDER กับ Stock · ใส่เครื่องหมาย · สรุปงาน

ต้องเตรียม หน้าในโปรแกรม งานนอกจอ ผลลัพธ์ เส้นทางหลักทุกวัน ข้อมูลที่ใช้ ระบบทำให้เอง

    แถบขวา: RZ Plan / Plan Order

    หน้าวางแผนสั่งซื้อและดูแลร้าน ใช้ข้อมูลที่อัปโหลดในหน้า นำเข้าข้อมูล กดการ์ดเพื่อดูวิธีใช้

    ⏰ โปรแกรมทำอะไรให้เอง

    • ทุกเช้าขึ้นวันใหม่ ล้างแบรนด์ที่เลือก + 🏷️ Wave ของทุกรอบ และล้างตัวกรองตาราง ORDER (เวลาที่ตั้งไว้ไม่หาย)
    • ตามรอบเวลาโหลด ORDER จาก BigSeller แล้วปริ้นใบหยิบตามแบรนด์ของรอบนั้น ถ้าติ๊ก 🏷️ ไว้ จะสร้าง Wave + พิมพ์ใบปะหน้าต่อ
    • ก่อนรอบ 15 นาทีเตือนถ้ารอบนั้นยังไม่เลือกแบรนด์ และเช็กว่ายังล็อกอิน BigSeller อยู่ ถ้าไม่พร้อมหรืองานล้มเหลว มีเสียง + แจ้งเตือนมุมจอของ Windows
    • ทุก 15 นาทีดึงสินค้าที่ขายอยู่ Shopee · Lazada · TikTok (ไม่ต้องเปิดหน้านั้น)
    • เปิดหน้า 1ดึง ST และ SI จาก BigSeller ให้ (ถ้าติ๊กไว้)
    • เที่ยงคืนล้างใบที่พร้อมและผลของหน้า ใส่เครื่องหมาย และประวัติการเบิกของวัน
    • มีรุ่นใหม่ปุ่ม อัปเดต ขึ้นบนแถบบนของโปรแกรม (เช็กทุกชั่วโมงและตอนเปิดโปรแกรม) กดแล้วตอบตกลง โปรแกรมติดตั้งรุ่นใหม่และเปิดใหม่ให้เอง ไม่ต้องส่งไฟล์ติดตั้ง

    ผลตรวจ ORDER กับ Stock

    • ✅ พอStock มากกว่าหรือเท่ากับ ORDER
    • ⚠️ ขาด XStock น้อยกว่า ORDER อยู่ X ชิ้น
    • ❌ ไม่มีไม่พบ SKU ในคลัง หรือ Stock เป็น 0

    ⌨️ ทางลัดที่ควรรู้

    • Tab เปิด/ปิดกล่อง ค้นหาสต็อก ได้ทุกหน้า (รวมหน้า BigSeller) · กดตำแหน่งเพื่อเลือกเบิก แล้วกด ⬇ โหลดใบย้าย หรือ 📥 นำเข้า BigSeller (ส่งเข้าหน้า ย้ายสินค้า ให้เอง ถามยืนยันก่อน) · SKU ที่เบิกไปแล้ววันนี้แถวเปลี่ยนสี (เหลือง 1 ครั้ง · ส้ม 2 · แดง 3+) และตำแหน่งที่เบิกไปแล้วมีป้าย เบิก n ต่อท้าย
    • Ctrl+B หรือปุ่ม 🌐 เปิดเบราว์เซอร์ในตัว (BigSeller)
    • กดหัวตารางตัวอย่างข้อมูล ORDER เพื่อเรียง ▲/▼
    • กดรหัส Parent SKU ในหน้า สินค้าที่ขายอยู่ = คัดลอก

    🛠 แก้ปัญหาที่เจอบ่อย

    ถึงเวลาแล้วไม่สร้าง Wave / ไม่พิมพ์ใบปะหน้า

    ดูปุ่มของรอบนั้นในหน้า รับORDER ต้องขึ้นว่า 🖨️ ปริ้น N ยี่ห้อ + 🏷️ Wave ถ้าขึ้น (ไม่ทำ Wave) ให้กดปุ่มแล้วติ๊ก 🏷️ และต้องล็อกอิน BigSeller ในเบราว์เซอร์ในตัวไว้ด้วย

    พิมพ์ใบปะหน้าไม่ออก ขึ้นว่าเลือกเครื่องพิมพ์ไม่ได้

    ระบบเลือกเครื่องพิมพ์ 4BARCODE 4B-2054K ให้ทุกครั้ง ถ้าเลือกไม่ได้จะหยุดและบอกรายชื่อเครื่องพิมพ์ที่เห็น เช็กว่าเครื่องพิมพ์เปิดอยู่และโปรแกรมพิมพ์ของ BigSeller (ปลั๊กอินพิมพ์) ทำงาน แล้วกดสร้าง Wave + พิมพ์ใบปะหน้าใหม่

    ถึงเวลาแล้วไม่โหลดเลย

    รอบที่ยังไม่ได้เลือกแบรนด์จะไม่โหลด (ปุ่มขึ้นว่า 🖨️ เลือกแบรนด์) ทุกเช้าแบรนด์ถูกล้าง ต้องเลือกใหม่ และโปรแกรมต้องเปิดค้างไว้ตอนถึงเวลา

    ขึ้นว่า "ไม่พบส่วนขยาย"

    ปิดแล้วเปิดโปรแกรมใหม่ ถ้ายังขึ้นอยู่ ให้ติดตั้งโปรแกรมทับด้วยตัวติดตั้งล่าสุด (RAYQUAZA2-Setup.exe)

    ขึ้นว่า "ยังไม่ได้ล็อกอิน BigSeller"

    กด Ctrl+B เปิดเบราว์เซอร์ในตัว เข้า bigseller.com แล้วล็อกอิน (แยกจาก Chrome) จากนั้นกดคำสั่งเดิมอีกครั้ง

    BigSeller ตอบว่าเรียกถี่เกินไป (too frequent)

    โปรแกรมรอแล้วลองใหม่ให้เอง ถ้ายังไม่ได้ รอ 1–2 นาทีแล้วกดใหม่

    แก้สต็อก / ราคาพิเศษ แล้วขึ้น "ไม่พบสินค้านี้"

    สินค้าถูกลบหรือเลิกขายไปหลังดึงข้อมูลล่าสุด กด ⚡ ดึงจาก BigSeller ใหม่ก่อน
